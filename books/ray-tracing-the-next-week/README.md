# Ray Tracing the Next Week
A zig implementation of [Ray Tracing the Next Week](https://raytracing.github.io/books/RayTracingTheNextWeek.html).

# Building and Running
To build the raytracer for this book, you must `cd` into the book's folder and run the following commands.
```bash
cd books/ray-tracing-the-next-week
zig build test
zig build run -Drelease=true
```

View custom build options with `zig build -h`.
